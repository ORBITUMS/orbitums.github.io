# Привет! Это мой личный сайт-портфолио 

Добро пожаловать в репозиторий моего первого веб-проекта! Это интерактивный сайт обо мне, созданный с использованием современных стандартов фронтенд-разработки (чистый HTML, семантика и методология БЭМ в CSS).

---

## 💻 О чём этот сайт?

Этот проект — моя визитная карточка в мире веб-разработки, где я рассказываю о себе, делюсь своими социальными сетями и экспериментирую с крутыми интерфейсными фишками.

### ✨ Основные разделы сайта:
*   **🏠 Дом (Главная):** Приветственная секция с информацией обо мне.
*   **📞 Связь:** Раздел со всеми моими актуальными контактами (Telegram, YouTube, GitHub, TikTok).
---

## 🛠 Технологии:
*   **HTML5** (Семантическая верстка)
*   **CSS3** (Flexbox, CSS-переменные, Медиа-запросы для адаптивности под телефоны)
*   **JavaScript** (Мини-скрипт для отслеживания кликов и переключения секретных фонов)
